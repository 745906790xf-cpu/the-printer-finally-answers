A tiny Python program that writes one line to /output/entry.txt for make.fun's The Printer Finally Answers bounty: the office printer's comeback to everyone staring at it. The line is a fixed string, so every run writes the same bytes.

> Paper jam, tray 2. I fed 12,438 sheets this month. I jammed on the one you needed.

## Run it

```sh
python3 main.py
```
